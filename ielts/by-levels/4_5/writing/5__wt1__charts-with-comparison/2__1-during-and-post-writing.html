Làm Chủ Ngôn Ngữ So Sánh

Nâng Band Điểm Task 1 Với Cấu Trúc & Từ Vựng Chuẩn

🛑 QUY TẮC VÀNG: SO SÁNH, KHÔNG PHẢI XU HƯỚNG!

Với biểu đồ so sánh (không có mốc thời gian), tuyệt đối KHÔNG dùng các từ mô tả xu hướng như `increase` hay `decrease`. Thay vào đó, hãy tập trung vào việc so sánh các đối tượng khác nhau tại cùng một thời điểm bằng các cấu trúc so sánh.

🛠️ Bộ Công Cụ Ngữ Pháp So Sánh

So Sánh Bằng: Khi các số liệu tương đương

  • A + V + as + adj/adv + as + B
  • A + be + the same as + B
  • A and B are similar

Ví dụ: "The number of boys was the same as the number of girls, at 1000."

So Sánh Hơn: Khi các số liệu khác biệt

  • Ngắn: adj/adv-er + than
  • Dài: more/less + adj/adv + than

Ví dụ: "The number of boys, at 1200, was significantly higher than the number of girls, at 800."

So Sánh Nhất: Khi một số liệu vượt trội

  • Ngắn: the + adj/adv-est
  • Dài: the most/least + adj/adv

Ví dụ: "USA had the highest number of viewers for Golf."

🚀 Từ Vựng "Ăn Điểm" Cho Bài So Sánh

Để chỉ sự tương đồng

  • A is similar to B
  • A and B are similar
  • Likewise, / Similarly,

Để chỉ sự tương phản

  • In contrast, / By contrast,
  • while / whereas
  • However,

Sử dụng đa dạng các cấu trúc so sánh là chìa khóa để đạt điểm cao trong tiêu chí Ngữ pháp (Grammatical Range and Accuracy).
