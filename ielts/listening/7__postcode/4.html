Giai đoạn 1: Pre-listening (P.O.S)

🔮 PREDICT - Dự đoán format

Context clues để predict:

  • • "UK address" → Format: XX## #XX
  • • "Australian mail" → Format: ####
  • • "Canadian postal" → Format: X#X #X#
  • • "American zip" → Format: ##### hoặc #####-####

Ví dụ prediction:

Context: "I live in Manchester, UK"

→ Predict: UK format

→ Template: XX## #XX

→ Expect: 6-7 characters

🧭 ORIENT - Định hướng địa lý

UK Regions

London: SW, SE, NW, NE, W, E, WC, EC

Manchester: M

Birmingham: B

Leeds: LS

Australia States

NSW: 1xxx, 2xxx

VIC: 3xxx, 8xxx

QLD: 4xxx, 9xxx

WA: 6xxx

Canada Provinces

ON: K, L, M, N, P

BC: V

AB: T

QC: G, H, J

🔍 SCAN - Quét tín hiệu ngôn ngữ

Signal phrases to scan for:

  • • "The postcode is..."
  • • "That's..." (confirmation)
  • • "Let me spell that..."
  • • "Sorry, I mean..." (correction)
  • • "Is that correct?" (verification)

Danger signals to watch:

  • • "Actually..." (change coming)
  • • "Wait..." (correction incoming)
  • • "No, sorry..." (false start)
  • • "Did I say...?" (doubt/change)
  • • "Let me check..." (uncertainty)

Giai đoạn 2: During-listening (T.C.O.D)

📡 TRACK - Theo dõi speaker patterns

Speaker characteristics to track:

Tempo Pattern

Fast → slow → fast = emphasis on slow part

Intonation Changes

Rising tone = question, falling = statement

Pause Patterns

Long pause = thinking/checking accuracy

Real example analysis:

🎧 Audio pattern:

"The postcode? [fast] It's BT23... [long pause, slower] no wait, BT32DF [clear, confident]"

Analysis: Pause + slower speech indicates correction

Strategy: Wait for confident, clear delivery

📝 CAPTURE - Ghi nhận chính xác

Multi-version notation system:

Notation example:

V1: BT23

V2: BT32AA

V3: BT32DF ✓

✓ = confident final version

Confidence indicators:

  • • Spelling out: "B for Bob, T for Tom"
  • • Repetition: Says it twice identically
  • • Confirmation: "Is that right?"
  • • Clear delivery: Slower, more distinct

📊 ORGANIZE

Real-time organization:

Audio: "B-T-3-2-D-F"

Capture: B T 3 2 D F

Organize: BT32DF

Format: ✓ 6 chars, letters+numbers

🎯 DISTINGUISH

Distractor elimination:

Version 1 (hesitant) ❌ Eliminate
Version 2 (corrected) ❌ Eliminate
Version 3 (confident) ✅ Keep

Giai đoạn 3: Post-listening (E)

⚡ EXECUTE - Thực thi chính xác

Final Check List

  • ☑️ Format matches prediction?
  • ☑️ Length seems reasonable?
  • ☑️ All uppercase letters?
  • ☑️ No spaces included?
  • ☑️ Final confident version?

Quick Verification

Geographic check:

UK context → Should start with area letters

Length check:

UK = 6-7 chars, AU = 4 chars, CA = 6 chars

Common Final Errors

  • • Added unnecessary spaces
  • • Mixed up similar sounds
  • • Used first version instead of final
  • • Incorrect capitalization

Ví dụ tích hợp P.O.S.T.C.O.D.E

Scenario: UK address with multiple distractors

P.O.S (Pre-listening):

Context: "Manchester address" → Predict: M## ### format

🎧 Audio simulation:

"The postcode for Manchester is M15... actually, let me double-check that. Sorry, it's M14 3JT. That's M-1-4 space 3-J-T. So M14 3JT."

T.C.O.D (During):

Track: Hesitation → correction pattern

Capture: M15 (crossed out), M14 3JT ✓

Organize: M143JT (no space for IELTS)

Distinguish: Final version after spelling

E (Post-listening):

Execute: M143JT

✓ Matches UK format ✓ Manchester area ✓ 6 characters

Result: Perfect capture using systematic approach

Traditional approach would likely capture "M15" (first version). P.O.S.T.C.O.D.E captures "M143JT" (correct final version).

P.O.S.T.C.O.D.E Strategy: Không chỉ là kỹ thuật nghe, mà là hệ thống nhận thức hoàn chỉnh cho Band 8-9.
